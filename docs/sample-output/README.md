# Sample Test Outputs

These artifacts are from a successful local execution against the public SauceDemo and
JSONPlaceholder demo services. They are committed so a reviewer can inspect real execution
evidence immediately after cloning the repository.

| Artifact | Result | Command used |
| --- | --- | --- |
| `ui-test-report.html` | 11 UI tests passed | `mvn -s .mvn/settings.xml -pl ui -am test -Denv=local` |
| `ui-test-run.log` | UI console log | Same UI command |
| `api-test-report.html` | 17 API tests passed | `mvn -s .mvn/settings.xml -pl api -am test -Denv=local` |
| `api-test-run.log` | API console log, including cURL requests and response validation | Same API command |

The HTML reports are self-contained summaries generated by `HtmlReportListener`. The API log
includes request cURL commands, response status/headers/body, and validation results. UI failure
screenshots and Playwright traces are generated only when a UI test fails, so they are intentionally
not included in this all-passing sample run.
